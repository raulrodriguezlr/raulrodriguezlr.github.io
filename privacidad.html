Política de privacidad

Aplicación: AI Video Creator · Última actualización: 1 de octubre de 2026

1. Quién usa esta aplicación

AI Video Creator es una herramienta de uso interno del canal de YouTube Órbita Piña. La utiliza únicamente el propietario del canal para gestionar su propia cuenta. No está disponible para otros usuarios ni se ofrece como servicio público.

2. Qué datos de Google utiliza

Con el permiso expreso del propietario, la aplicación accede a su cuenta de YouTube a través de las API de Google para:

  • Subir vídeos al canal del propietario y editar su título, descripción, etiquetas, miniatura y visibilidad.
  • Leer la información básica del canal (nombre, identificador y estadísticas públicas).
  • Consultar las estadísticas del canal en YouTube Analytics (visualizaciones, retención, audiencia) para mejorar los propios vídeos.

La aplicación no accede a datos de otros usuarios de YouTube ni de Google.

3. Cómo se guardan los datos

El token de acceso que emite Google se guarda solo en el ordenador del propietario del canal. Las estadísticas consultadas se usan para analizar el rendimiento del canal y no se almacenan en ningún servidor externo.

4. Con quién se comparten

Con nadie. Los datos obtenidos de las API de Google no se venden, no se ceden a terceros y no se usan con fines publicitarios.

El uso y la transferencia de la información recibida de las API de Google cumplen la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

5. Cómo revocar el acceso

El acceso puede retirarse en cualquier momento desde la página de permisos de la cuenta de Google. Al revocarlo, la aplicación deja de poder acceder a la cuenta.
